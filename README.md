## Featured Projects

### [AeroForge](https://github.com/PetarCovic/AeroForge)

A modular C++20 aerospace simulation platform featuring 6DOF rigid-body dynamics, numerical integration, guidance and control components, Monte Carlo analysis, and interactive visualization.

Includes numerical validation, deterministic replay, and performance benchmarking.

### [SentinelMesh](https://github.com/PetarCovic/SentinelMesh)

A distributed IoT security monitoring platform built with Java and Spring Boot, featuring real-time event processing, device monitoring, alerting, and camera integration.

Load-tested with over 100,000 simulated security events, achieving approximately 690 events per second.

### [SentinelOS](https://github.com/PetarCovic/SentinelOS)

An experimental x86 operating system developed using C++ and assembly, exploring multistage bootloading, kernel development, physical memory allocation, hardware interaction, and low-level debugging.
